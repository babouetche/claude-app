# Babou Art — montage photo & vidéo sur iPhone

Web-app installable (PWA). Tout est traité sur le téléphone, le projet est sauvegardé automatiquement.

- **Timeline multi-pistes** : clips vidéo/photo, textes, stickers, incrustations, dessins, musiques, voix off
- **Clips** : diviser, couper (poignées), vitesse, volume, filtres, réglages, effets (zoom, flash, glitch…), transitions, recadrage au doigt, détourage IA, visages (flou/emoji/remplacement), réordonner, dupliquer
- **Textes** : 11 styles rapides, 10 polices, contour/ombre/pastille/néon, animations d'entrée/sortie/boucle, karaoké mot par mot
- **Sous-titres auto** (IA Whisper, FR/EN/ES), modifiables en liste
- **Modèles** prêts à l'emploi (annonce de cours, hook, tuto, promo, compte à rebours…)
- **Formats** 9:16, 1:1, 4:5, 3:4, 16:9 ; fond flou/couleur/image
- **Export** MP4 720p/1080p ou image PNG → Photos / TikTok / Insta

**Installation** : ouvrir l'URL GitHub Pages dans Safari → Partager → « Sur l'écran d'accueil ».
