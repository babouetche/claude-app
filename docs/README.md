# Shape Studio — montage photo & vidéo sur iPhone

Web-app installable (PWA), tout est traité sur le téléphone.

**Fonctions** : retirer/remplacer le fond (couleur, flou, image, transparent) · textes et sous-titres (dont sous-titres auto en français) · musique (volume, point de départ, photo + musique → vidéo) · visages (flouter, emoji, remplacer par un autre visage) · dessin au doigt · luminosité/contraste/saturation · couper la vidéo · export MP4/PNG vers Photos.

**Installation** : ouvrir l'URL GitHub Pages dans Safari → bouton Partager → « Sur l'écran d'accueil ».
