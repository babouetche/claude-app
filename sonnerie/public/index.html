🔔 Sonnerie iPhone

Installer sur l'iPhone
  1. Télécharge le fichier sonnerie.m4r (app Fichiers).
  2. Avec un Mac : branche l'iPhone, glisse le fichier dans Finder > Général > Sons.
  3. Sans Mac : importe le fichier dans GarageBand > Partager > Sonnerie.
  4. Réglages > Sons et vibrations > Sonnerie.
